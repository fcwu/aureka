# Aureka 本機測試環境

本機開發環境設定，不進 git。

---

## 服務端點

| 服務 | URL | 說明 |
|------|-----|------|
| Daemon | `http://127.0.0.1:7777` | `python -m aureka daemon start` |
| Mock LLM | `http://127.0.0.1:11434` | `python tests/scripts/mock-llm-server.py` |
| LM Studio（可選） | `http://127.0.0.1:1234` | Windows 原生 LM Studio |

## 裝置資訊

- **GPU**：AMD AI MAX 395+（ROCm，WSL2 環境無 GPU 加速）
- **ASR 後端**：faster-whisper（CPU）
- **TTS 後端**：Kokoro（CPU）

## 測試設定

```toml
# tests/config.test.toml（測試專用 config）
[llm]
base_url = "http://127.0.0.1:11434/v1"
api_key  = "mock"
model    = "mock-model"

[vlm]
base_url = "http://127.0.0.1:11434/v1"
api_key  = "mock"
model    = "mock-vision-model"
```

## 啟動 / 停止指令

```bash
# 啟動 daemon（測試模式，跳過模型載入）
AUREKA_TEST_MODE=1 AUREKA_CONFIG=tests/config.test.toml python -m aureka daemon start

# 停止
python -m aureka daemon stop

# 啟動 mock LLM server
python tests/scripts/mock-llm-server.py --port 11434 &

# 生成測試夾具
python tests/scripts/gen-test-audio.py
```

## 注意事項

- WSL2 環境：GPU 不可用，所有 Device 層級測試標 `needs-user-action`
- LM Studio 在 Windows 側，若需真實 LLM 測試可從 WSL2 存取 `http://127.0.0.1:1234`
